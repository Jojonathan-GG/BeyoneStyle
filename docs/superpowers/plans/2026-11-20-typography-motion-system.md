# Typography & Motion Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give BeyoneStyle a runnable Next.js app with a Plus Jakarta Sans / Inter type system, light editorial surface tokens, restrained motion tokens, and a seamless CSS marquee.

**Architecture:** A greenfield Next.js 16 App Router app styled with Tailwind v4's CSS-first `@theme`. Fonts are self-hosted through `next/font`. Tokens and component styles live in `app/globals.css`; the only interactive-looking piece, `Marquee`, is a server component animated purely in CSS.

**Tech Stack:** Next.js 16.4.6, React 19.3.1, TypeScript 5.9.3 (strict), Tailwind CSS 4.3.5, Vitest 5 + Testing Library (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-20-typography-motion-system-design.md`

## Global Constraints

- Node 24 is installed; npm 11.9.0; git 2.45.1. Commands run in PowerShell.
- Package versions: next 16.4.6, react/react-dom 19.3.1, typescript ^5.9.3, tailwindcss ^4.3.5, eslint ^9.39.5, eslint-config-next 16.4.6, vitest ^5.1.1.
- TypeScript strict; no `any`.
- Server Components by default; no `'use client'` in this plan.
- Colors (verbatim): `--color-surface: #ffffff`, `--color-surface-muted: #f7f7f4`, `--color-surface-sunken: #efefea`, `--color-ink: #111110`, `--color-ink-muted: #5c5c56`, `--color-ink-subtle: #8a8a82`, `--color-border: #e4e4dd`, `--color-border-strong: #cfcfc6`, `--color-accent: #111110`.
- Type roles: display = Plus Jakarta Sans (`--font-jakarta`), body/UI = Inter (`--font-inter`).
- Tracking: display `-0.045em`, display-l `-0.04em`, h1 `-0.035em`, h2 `-0.03em`, h3 `-0.02em`, body `0`, eyebrow `+0.12em` uppercase.
- Motion: animate `opacity`/`transform` only. Durations 150/250/400ms; easing `cubic-bezier(0.22, 1, 0.36, 1)` and `cubic-bezier(0.65, 0, 0.35, 1)`.
- Marquee default loop: 38s; pause on hover and `focus-within`; duplicate group must be `inert` + `aria-hidden`.
- Reduced motion: global transition/animation kill switch plus a marquee-specific static fallback.
- Do not add a dark theme, Shadcn components, GSAP, Three.js, or Framer Motion in this plan.
- Every price, count, and comparison figure uses the `.nums` utility (tabular lining numerals).

## Review Focus

- **Keyboard users inside the marquee:** focus must never land on the duplicate group, or screen-reader and Tab order duplicate content. Task 3 pins `inert` + `aria-hidden`.
- **`prefers-reduced-motion` users:** the marquee must not auto-scroll; it must become a static, natively scrollable row. Task 3's CSS contract test pins the fallback.
- **Price alignment:** proportional numerals make price columns ragged. Task 2 pins `font-variant-numeric: tabular-nums`; Task 4 applies `.nums`.
- **Empty content:** `<Marquee items={[]} />` must render nothing rather than an empty 38s track. Task 3 tests this.
- **Narrow viewports:** a marquee must not create horizontal page scroll at 375px. Task 4 verifies at 375px and 1440px.

- [ ] **Step 4: Implement `components/ui/marquee.tsx`**

```tsx
import type { CSSProperties, ReactNode } from 'react';
import { cn } from '@/lib/utils';

export type MarqueeVariant = 'announcement' | 'category';

export type MarqueeProps = {
  items: ReactNode[];
  variant?: MarqueeVariant;
  speed?: number;
  className?: string;
  ariaLabel?: string;
};

export function Marquee({ items, variant = 'announcement', speed = 38, className, ariaLabel }: MarqueeProps) {
  if (items.length === 0) return null;

  return (
    <section
      aria-label={ariaLabel}
      data-variant={variant}
      className={cn(
        'marquee',
        variant === 'announcement'
          ? 'bg-ink text-surface text-eyebrow font-medium'
          : 'border-y border-border bg-surface text-ink font-display text-lg tracking-[-0.02em]',
        className,
      )}
    >
      <div className="marquee-viewport">
        <div className="marquee-track" style={{ '--marquee-duration': `${speed}s` } as CSSProperties}>
          {[0, 1].map((group) => (
            <div
              key={group}
              className="marquee-group"
              data-duplicate={group === 1 ? 'true' : 'false'}
              aria-hidden={group === 1 || undefined}
              inert={group === 1 || undefined}
            >
              {items.map((item, index) => (
                <div key={index} className="marquee-item">
                  {item}
                </div>
              ))}
            </div>
          ))}
        </div>
      </div>
    </section>
  );
}
```
